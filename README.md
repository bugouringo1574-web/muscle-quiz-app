# 筋肉・骨格マスター！楽しくおぼえる人体の解剖学アプリ 💪💀

小学6年生から大人まで、楽しく・直感的に人体の骨格筋や骨の名称を覚えられるWeb学習クイズアプリです。

## 🌟 主な機能・収録テーマ

### 1. 収録テーマ（全5ジャンル・計72問！）
- 🧍‍♂️ **筋肉（前面）**（18部位）: 大胸筋、腹直筋、大腿四頭筋、ヒラメ筋など
- 🏃 **筋肉（裏面）**（12部位）: 僧帽筋、広背筋、大臀筋、ハムストリングス、腓腹筋など
- 📐 **筋の形状**（5種類）: 紡錘状筋、二頭筋、羽状筋、多腹筋（腱画）、鋸筋
- 💀 **骨格（前面）**（19部位・テスト番号1〜19番）: 頭蓋骨、胸骨、肋骨、胸郭、脊柱、骨盤、腸骨、恥骨、坐骨、鎖骨、肩甲骨、上肢帯、上腕骨、橈骨、尺骨、大腿骨、膝蓋骨（ひざの皿）、腓骨、脛骨 ★NEW!
- 🦴 **骨格（後面）**（18部位＋脊柱4区分）: 頭蓋骨、肩甲骨、肋骨、寛骨、大腿骨、頸椎・胸椎・腰椎など

### 2. 学習スタイル
- 📖 **ずかんモード**: 人体図のピン（○）をタップして、名前・ふりがな・はたらき・💡おぼえ方ヒント（豆知識）を確認。覚えたら「💮覚えた！」チェック可能。
- 🎯 **4択クイズモード**: 図の中でピカピカ赤く点滅する部位の名前を4択から選ぶクイズ。
- 👆 **タップクイズモード**: 「膝蓋骨（ひざのお皿）はどこ？」などの問題に対して、図のピンを直接タッチして答える直感クイズ。

### 3. テスト暗記機能（自動文字マスク）
- クイズモード時は、**問題の答えとなる教科書の印刷文字領域を自動で完全マスキング**！答えを見ずに自力で場所と名称を思い出す真剣テストができます。
- ずかんモードでも「🙈 文字をかくす」ボタンでいつでも暗記シートのように切り替え可能です。

### 4. スマホ対応（Wi-Fi経由で直接遊べる！）
- レスポンシブデザインで、スマホの縦画面でも押しやすいボタン配置とピン操作に対応。
- ヘッダーの「📱 **スマホで開く**」ボタンを押すと**QRコード**が表示され、同一Wi-Fi内のスマホカメラでかざすだけで即アクセスできます。

### 5. 音声・演出
- Web Audio APIによる正解音（ピンポーン♪）、不正解音、満点時のファンファーレ＆紙吹雪エフェクト。

## 🚀 使い方

### Macのブラウザで遊ぶ
ローカルサーバーが起動している状態で以下にアクセス：
👉 **http://localhost:8085/**

### スマホで遊ぶ
Macと同じWi-Fiにスマホを接続し、スマホのSafariやChromeで以下を開く（またはアプリ内のQRコードをカメラで読み取る）：
👉 **http://192.168.10.111:8085/**
